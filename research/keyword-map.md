## Full keyword mapping

Repository match types: **topic** means a relevant starting point, **brand/ecosystem** means the named project or an associated SDK/CLI. A public SDK or issue/plugin repository does not imply the entire commercial product is open source. Hermes Atlas, Hermes Studio, and Oh My Hermes use the parent ecosystem as a starting point; distinct repositories were not verified. Browserbase maps to its Stagehand SDK. OpenRouter maps to its TypeScript SDK; the primary SDK page notes a separate agent-package migration.

Moltbook columns list up to three communities returned for that exact query, followed by one indexed post. These are discovery candidates, not a manually qualified list of every result. Search can return semantic or incidental matches; an absent exact brand match remains unverified even if there are results.

## Method and qualifications

- Sources: structured keyword catalog, matcher vocabulary, primary GitHub repositories linked above, and authenticated Moltbook GET search responses. [Moltbook search API reference](https://www.moltbook.com/skill.md).
- Moltbook requests used `type=posts&limit=10`; no pagination, recency filter, or comment inspection. Search ranking can favor old posts and repeated authors. This report does not establish current agent-to-agent conversation activity.
- Initial search failures were retried more slowly. Each row preserves failure or zero-result distinctions. No community subscription changes, GitHub stars/watches, outreach, or scheduled monitoring were performed in this pass.
- Public repository existence and topic fit were checked through primary web sources. Code quality, license suitability, current maintenance, and identities of maintainers were not audited. Read recent issues/PRs and attribute specific work before developer outreach.
- No verified repository match means unresolved in this pass, not proof that no repository exists. Avoid substituting lookalikes or unrelated projects for ambiguous commercial brands.
- The previously joined Reddit communities remain documented in Top agent communities (workspace source: `CRM/research/TOP_AGENT_COMMUNITIES.md`).
