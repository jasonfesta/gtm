# Gmail draft preparation

This template supports a requested draft-preparation task; the [Email Agent](../../../agents/email-agent/README.md) owns Smartlead delivery.

Verify the connected mailbox against the private operator binding. Read [voice](../copy.md), [copy workflow](../WORKFLOW.md) and [contact rules](../../Rules.md). Use the requested bounded recipient set with source-backed identity, verified route and current suppression/history checks.

Prepare contextual alternatives only when requested. Preserve exact addresses and links, immutable revisions and the user's manual edits. Reserve the canonical draft before any authorized connector creation, save its provider ID and read back the resulting draft. Reconcile uncertain creations before retrying. A draft never counts as a sent message.

This template does not authorize sending, scheduling or a provider purchase. Keep recipient copy, drafts and evidence private; pass verified outcomes to Ops when applicable.
