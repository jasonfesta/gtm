# Final voice guide synthesis skeleton

Use this structure to replace provisional copy.md after the example collection is complete. Preserve the explicit developer-peer direction in copy.md: developer-only fit, short direct introductions, sender/product/one supported offer and one verified final link, with draft/critique/rewrite checks. Fill sections from supplied examples and explicit feedback; retain unresolved items as pending. This is a guide outline, never a fill-in message script.

## Status and provenance

Calibration status, version/date, operator, input example IDs, explicit feedback, approved reference path and deployment receipt. Preserve previous versions privately.

## Shared voice and tonality

Describe formality, warmth, directness, enthusiasm, humor, contractions, vocabulary and conversational stance. Tie conclusions to example IDs and separate user preferences from inferences. Describe how tone changes with relationship and purpose.

## Punctuation, casing and rhythm

Record observed use of periods, commas, questions, exclamations, dashes, ellipses, emoji, fragments, sentence counts, paragraph breaks, greetings and sign-offs. Preserve exact identifiers. Do not manufacture quirks absent from the examples.

## Length by channel and mode

For email subject/body, LinkedIn DM/public reply, X DM/public reply and incoming conversation responses, record sample count, character range/median, preferred character band, word limits and supported exceptions. Measure spaces/punctuation/newlines consistently using the daily workflow. Missing samples remain unknown; never infer all modes from one channel.

## Context and channel judgment

Explain what makes a recent detail useful, when to omit a pitch/question/link, and how cold outreach differs from an existing conversation. Use actual posts for public replies and actual incoming text for private responses. Recipient facts from examples never transfer to new people.

## Fresh LLM generation each session

Read this saved guide, brief, approved relevant examples and fresh person context. Write new prose rather than reusing openings or scripts. Match tonal and punctuation habits and measured length bands without copying examples. Prepare the three channel drafts up front, then refresh context and revise each due draft in its delivery session.

## Habits to avoid and exceptions

List supported dislikes, repetition patterns and context-dependent exceptions with example IDs. Explicit feedback wins. State uncertainty instead of inventing rules.

## Review and audit

Check specificity, evidence, tone, punctuation, characters/words, channel fit and batch repetition. Save guide version/hash, example references, context evidence and immutable draft revision in the private run record. Follow WORKFLOW.md for planning, deployment and receipt handling.
