# Public-post reply guidance

Read [copy.md](../copy.md) and approved examples for the exact platform. Current guide finalized from explicit direction; no example-derived calibration is claimed.

Read the actual post and relevant thread; preserve the author and exact permalink locally. Respond to something worth responding to. Do not require a praise-plus-summary opening or manufacture a question. A/B alternatives have no predetermined structure.

Use a short lowercase response to the actual post. A disclosed product introduction with one final verified link is allowed only when directly useful to that post, up to 30 words; otherwise use the 3–12 word reaction format. Omit filler, signatures and requests to DM. Existing sender restrictions still apply; linked drafts remain local where unsupported. An unavailable post remains a hold; never fabricate a real example.

Public replies remain private Markdown until distinct tool storage exists. Do not store them as private-message replies.
