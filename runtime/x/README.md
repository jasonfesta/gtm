# X account resources

This folder holds portable X account configuration. Current public reply execution belongs to [Human Reply](../../agents/human-reply-agent/README.md); private conversation handling belongs to [Human DM](../../agents/human-dm-agent/README.md); source collection belongs to [Human Discovery](../../agents/human-discovery-agent/README.md).

Each run verifies its signed-in account, uses its own browser lease and preserves private history. Account examples do not authenticate a session, activate a schedule or authorize an action. Preserve real prior sends, suppressions and uncertain attempts when changing source paths.
